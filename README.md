### 🔭 Featured project

**[Claude RAG Lab](https://github.com/nibrasqureshii/claude-rag-lab)**: an observable retrieval-augmented generation pipeline I built to teach developers how RAG works, one visible step at a time.

`Python` · `Streamlit` · `ChromaDB` · `sentence-transformers` · `Claude API` · `pytest`

- Loading → chunking → local embeddings → vector search → top-K retrieval → prompt assembly → Claude
- Side-by-side experiments comparing answers with and without RAG, to show grounding and hallucination
- ~1,800 lines of Python and 19 tests
